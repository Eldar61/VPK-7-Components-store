# Магазин комплектующих Семёна

Рабочий план: docs/PLAN.md. Контракт: docs/API.md. Данные каталога: data/catalog.json, источники data/sources.json.

- Собственная PostgreSQL; никакого чтения БД сборщика. JSON-контракт не зависит от его C#-сборок.
- Запись продаж только в confirm; резерв не является продажей. Не менять снимки подтверждённых позиций.
- Все изменения склада и резервов проходят через транзакцию PostgreSQL и общий advisory lock.
- Не выдавать совместимость без успешного ответа API Эльдара.
- После изменений: dotnet build PcShop.slnx; dotnet run --project tests/PcShop.Tests; scripts/smoke.ps1 при работающей тестовой БД. UI: npm.cmd run build.
- Не менять исходники сборщика без необходимости. Секреты в переменных окружения; реальные цены и остатки не заявлять: каталог учебный.
