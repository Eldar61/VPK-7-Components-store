# Происхождение и границы каталога

Дата проверки источников: 8 ноября 2026 года. Начальные данные — снимок, не живая синхронизация магазина.

442 артикулы: CPU 61, MOTHERBOARD 55, RAM 62, GPU 57, PSU 50, CASE 88, STORAGE 69. Уникальность контролируется по SKU и детерминированному UUID. Разные реально существующие объёмы/мощности/цвета/исполнения считаются отдельными поставляемыми товарами.

## Официальные источники

- AMD Processor Specifications: https://www.amd.com/en/products/specifications/processors.html — модель, AM4/AM5, TDP. Использованы настольные Ryzen 5000 на AM4 и AM5; мобильные и серверные CPU не добавлялись.
- Intel ARK: точные страницы i3-14100F и i5-14600K в data/manual-facts.json.
- MSI: полные Specification-страницы плат и видеокарт; для недоступных страниц — официальные PDF https://storage-asset.msi.com/datasheet/. Импорт включает только записи с прочитанными обязательными характеристиками.
- Kingston: официальные PDF https://www.kingston.com/datasheets/ с точным номером модуля. Взяты одиночные настольные 288-pin DDR4/DDR5 DIMM; SO-DIMM и комплекты не представлены как один модуль.
- Corsair: официальные страницы продуктов и их публичные структурированные характеристики. Артикулы CP-... для БП, CC-... для корпусов, CSSD-... для внутренних SSD.
- Fractal Design: официальные страницы конкретных корпусов, раздел Specifications.
- Samsung: официальный паспорт 870 EVO (250GB, 500GB, 1TB, 2TB, 4TB), ссылка в manual-facts.json.

Для каждого артикула data/sources.json хранит URL, дату, использованные факты, пояснения и SHA-256 локального исходного HTML там, где он был загружен этим сборщиком данных. PDF и исходные страницы сохранялись в игнорируемом .local/sources; пересоздавать их при обычном запуске магазина не нужно. Для фактов, проверенных отдельно через просмотр спецификации, hash может быть null.

## Что не является паспортным измерением

- Цена в рублях и остаток заданы учебными значениями, не являются предложением производителя или реального магазина.
- AMD: estimatedPowerW = ceil(TDP × 1,35), учебная оценка; TDP не равен потреблению.
- Intel: оценка по Maximum Turbo Power.
- Платы: 35 Вт без CPU/RAM/GPU.
- RAM: 4 Вт на DDR4 DIMM, 6 Вт на DDR5 DIMM.
- GPU: значение MSI Power consumption; при нескольких значениях взято максимальное.
- Corsair M.2 SSD: 8 Вт; Samsung SATA SSD: 5 Вт, учебные оценки.
- Корпуса Fractal: оценка 3 Вт на явно перечисленный штатный вентилятор. Corsair: обобщённая оценка корпусных вентиляторов 6 Вт.
- БП: nominal ratedPowerW; собственное потребление в круговую диаграмму не включается.

Для БП словарь разъёмов описывает консервативную схему штатного подключения: альтернативные кабели не суммируются автоматически. Для единственного 16-pin подключения 12VHPWR/12V-2x6 указаны совместимые ключи, а не два независимых кабеля. Карты с отдельным 6-pin не включены в этот снимок, чтобы не изображать совместное использование одной группы 6+2 как независимые ресурсы в ограниченном контракте сборщика.

Комбинированные места накопителей Fractal выделены под 3.5, а 2.5 считаются по отдельным креплениям: нельзя одновременно посчитать одно место дважды. Для корпусов Corsair неописанные в карточке места не заявляются как имеющиеся. Это консервативная граница модели, а не утверждение об отсутствии физического крепления в настоящем корпусе.

Полнота ПК соответствует семи категориям согласованного контракта. Проверка BIOS, кулера CPU, пропускной способности PCIe, длины M.2, ограничения RAM со стороны CPU, толщины GPU, положения радиаторов и разделяемых портов требует расширения обеих моделей. Ссылку на полный паспорт необходимо использовать при реальной покупке.

## Обновление каталога

Runtime использует готовый data/catalog.json, без сети к производителям. Seeder добавляет отсутствующие товары и сохраняет администраторские изменения существующих.

Скрипты scripts/collect-catalog.cjs и scripts/build-catalog.cjs — вспомогательная подготовка данных, не часть обработки запросов. Для пересборки нужны Node.js и pdfjs-dist в .local/catalog-tools; список первичных URL и ручных фактов остаётся в исходниках. Исходные HTML сайтов могут менять структуру: после повторного импорта проверяйте исключённые записи, численные характеристики и итоговые количества. Не заменяйте ошибки чтения случайными значениями. Текущий build-catalog отказывается выпускать каталог, если в любой категории менее 50 проверенных записей.
