# Сервис сборки ПК

Рабочая спецификация: README.md, docs/API.md и план в ../План проекта/PLAN (1).md. Проект принадлежит Эльдару; магазин Семёна находится за HTTP-контрактом.

- Чистые технические правила находятся в PcAssembly.Domain и не вызывают HTTP/БД.
- Цены, скидки, остатки, резервы и продажи принадлежат магазину. Здесь хранить только конфигурации и ссылки на магазинную корзину.
- После изменения правил: `dotnet run --project tests/PcAssembly.Tests`. После изменения API/сохранения: `scripts/smoke.ps1` на локальной БД и стенде магазина. После изменения UI: `cd frontend; npm run build`.
- Сохранённые сборки неизменяемы, повторное сохранение не увеличивает статистику. Сетевой сбой магазина не равен технической несовместимости.
- Меняя DTO или маршрут интеграции, обновляйте docs/API.md и OpenAPI. Не сохраняйте реальные ключи/пароли в репозитории.
